# cn-trip

`cn-trip` 是一个用于中国境内自由行规划的 Codex skill。

它的目标不是只给一段旅游文案，而是把一次旅行拆成可执行的结构化方案，包括：

- 目的地建议
- 主方案与备用方案行程
- 单人预算与预估总预算
- 返程计划
- 火车/机票参考信息
- 酒店、门票、餐饮等分项预算
- 美食店铺推荐
- 景点历史人文介绍
- 最终多 sheet Excel 导出约束

## 适用场景

适合以下需求：

- 还没决定去哪，想先筛目的地
- 已经有目的地，想生成完整自由行方案
- 想同时拿到主方案和备用方案
- 想把预算拆到交通、酒店、门票、餐饮等具体安排
- 想把结果整理成 Excel

当前定位：

- 只做中国境内自由行
- 不做出境游
- 不负责机酒预订
- 不承诺实时导航

## 主要能力

`cn-trip` 会按步骤工作：

1. 逐步提问，收集约束条件
2. 推荐目的地或校验用户已有目的地
3. 先做单人预算拆分，再判断方案是否可行
4. 查攻略与高可信来源，整理交通、玩法、避坑点
5. 生成主方案和备用方案
6. 整理成结构化 Excel 内容

## Excel 输出结构

默认输出 8 个 sheet：

1. `行程总览`
2. `详细行程（主方案）`
3. `详细行程（备用方案）`
4. `预算拆分`
5. `出行准备清单`
6. `美食攻略`
7. `景点历史人文`
8. `信息来源`

其中：

- `美食攻略` 包含店铺推荐、位置、推荐菜、人均、避坑点
- `详细行程` 会联动推荐店铺
- `预算拆分` 会尽量细到具体安排，例如车次费用、酒店费用、门票费用、餐饮费用

## 使用方式

把 `cn-trip` 目录放到本地 Codex skill 目录后即可使用，常见位置是：

```text
~/.codex/skills/
```

示例：

```text
用 $cn-trip 帮我规划一个国内自由行
```

```text
我想 8 月从上海出发去西藏玩 8 天，单人预算 5000，$cn-trip
```

## 说明

这个仓库当前包含的是 skill 定义本身，不等于自动具备稳定的本地 `.xlsx` 导出程序。

也就是说：

- skill 可以定义导出规则和输出结构
- 真正稳定生成 Excel，仍建议配合本地导出器或受控导出脚本
